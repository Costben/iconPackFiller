> *Complete the missing icons of any launcher theme — in its own style, generated by AI.*
> 给任意第三方启动器图标包补全缺失图标：同画风、AI 生成、无需 root。

从已安装的图标包（appfilter APK）出发，扫描本机尚未适配的应用，用 AI 图像模型
生成同画风图标，再原地注入、签名，打包成可直接安装的完整合并包。
本仓库不做任何系统写入，不依赖 Shizuku / root；与 ArtPlus（root 版）共享图标包交换格式。

## ✨ 特性

- **无 root 全流程**：选包 → 覆盖报告 → 生成 → 打包签名 → 安装，一个 App 内闭环
- **原地增量打包**：ARSCLib 直接改写原包 `resources.arsc` + 编译型 `appfilter.xml`，
  包名 `dev.artplus.iconpack.<hash8>` 与原包共存，可装多个补全包
- **启动器兼容**：ADW / Nova / Lawnchair / Smart / MS / AndDoes / Atom / GO
  八家 theme intent-filter，Lawnchair 真机实测通过（见 `docs/launcher-compat.md`）
- **透明直出 + 键色兜底**：gpt-image 家族走 `background: transparent` 免抠图；
  其他模型自动切绿幕/红蓝自适应键色，本端三阶段 flood 抠图 + 去光晕
- **多供应商槽位**：OpenAI Images / Responses / Chat 三协议自适应，可保存多套 Key，
  复制槽位、模型选择器（21 家厂商 logo）开箱即用
- **可回溯**：每次执行记一批次，attempt 落盘；单图标可换参考重生成；历史对比预览
- **Miuix 风格 UI**：单 Activity 多步骤页，深色模式可用

## 🚀 快速开始

**前提**：自备 OpenAI 兼容的图像生成网关（BYOK，本应用不附带任何 Key 或额度）。

```bash
./gradlew :app:assembleDebug      # 输出 app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest  # JVM 单测（300+）
```

1. 安装 APK → 右上角进 **设置**，填供应商 Base URL / 模型 / Key，点保存
2. 首页选一个已安装图标包（或导入 APK），点 **扫描应用**
3. 在覆盖报告里勾选要补的应用 → **开始生成**
4. 生成完点 **安装**，再去启动器里应用这个补全包

```bash
./gradlew :app:assembleRelease    # 需要自备 release.jks + KEYSTORE_PASSWORD
```

构建工具：Android Gradle Plugin 9.3.2、Kotlin 2.4.10、Compose BOM 2026.08.00、
minSdk 26、targetSdk 37、compileSdk 37。

> 安全说明：`app/src/main/assets/filler-signing.p12`
> 是补全包共用的**公开身份证书**（所有补全包同证书，便于启动器识别同一来源；
> 口令硬编码在 `ApkSigner.kt`，随应用分发，人人可提取——设计如此，不构成安全边界）。
> 它只签生成的图标补全包，不签本应用。**发布本应用请用自己的 `release.jks`**
>（`KEYSTORE_PASSWORD` / `KEY_PASSWORD` 经环境变量或 `local.properties` 传入，
> 两者均不在版本库中）。
